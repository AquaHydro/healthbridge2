# HealthBridge 原型：主流程、页面清单与待确认假设

> 依据：`HealthBridge-开发方案.md` v0.1 第 1.1、3.3、5、6 节 · 2026-11-03
> 标注 ★ 的内容是方案文档里没有、由本文补充的设计，需要确认。

## 1. 主流程

```
首次启动
 ① 介绍 ──「连接我的服务器」──▶ ② 连接服务器 ──测试通过──▶ ③ 数据共享同意
   │                              │                          │        │
   │                              │「暂不连接」★            同意并继续  不同意 ★
   │                              ▼                          ▼        ▼
   └──「仅在本机查看」★ ──────▶ ④ʟ 选择概览类型 ★        ④ 选择数据类型 + 首次同步范围
                                  │                          │
                                  ▼                          ▼
                               ⑤ HealthKit 授权          ⑤ HealthKit 授权
                                  │                          │
                                  ▼                          ▼
                             主界面（本机模式）           ⑥ 首次同步进度 ──▶ 主界面（同步模式）
```

- **同步模式**：已连接服务器 + 已同意 → 后台增量上传。
- **本机模式** ★：未连接，或连接了但不同意 / 已撤回同意 → 只从 HealthKit 读本机数据做概览，不发起任何上传请求。
- 本机模式随时可从「同步」Tab 或「设置 › 服务器」进入连接流程（② → ③ → ⑥，已授权的类型不再弹 HealthKit 授权）。

## 2. 页面清单

### 引导（全屏，NavigationStack，不可跳过同意页）
| ID | 页面 | 主要内容 / 组件 |
|---|---|---|
| O1 | 介绍 | 图标占位、三条要点、数据流向图（iPhone → 你的 Cloudflare → AI Agent）、时效性说明（几分钟到一小时）；主按钮「连接我的服务器」，次按钮「仅在本机查看」 |
| O2 | 连接服务器 | 默认扫码或粘贴部署完成后的短时连接链接；确认服务器后自动交换凭据。手动连接移到次级入口：Worker 地址、写入 Token（SecureField + 粘贴）；「测试连接」；结果行：成功（版本、各类型已有样本数）/ Token 错误 / 地址无法访问 / 服务端版本过旧；「如何部署」链接；工具栏「暂不连接」 |
| O3 | 数据共享同意 | 独立页面。说明发送到哪里、发送什么、谁可能读取（你接入的第三方 AI Agent，如 Claude、Codex）、开发者无法访问、可随时撤回；隐私政策链接；「同意并继续」/「不同意，仅在本机查看」，无默认勾选 |
| O4 | 数据类型与范围 | List + Toggle（睡眠、心率、静息心率、心率变异性、步数，默认全开，带健康配色图标）；Picker：首次同步范围 7 / 30 / 90 / 365 天 / 全部（默认 30 天） |
| O5 | HealthKit 授权 | 说明页 → 调起系统授权表单（原型中模拟系统表单）；说明「iOS 不会告诉 App 你是否拒绝了某项读取」 |
| O6 | 首次同步进度 | 每类型一行 ProgressView + 已上传条数；可「在后台继续」进入主界面；失败行可重试 |

### 主界面（TabView）
| ID | Tab | 内容 |
|---|---|---|
| T1 | 概览 | 顶部同步状态条（同步模式：「上次同步 12 分钟前」；本机模式：「本机模式 · 未上传」）；卡片：睡眠（昨晚时长 + 阶段条 + 7 天柱状图）、静息心率、心率变异性、步数、心率（今日范围图）。点卡片进二级详情（7 天 / 30 天切换） |
| T2 | 同步 | 总状态（Section header）、每类型行：最后样本时间 / 最后上传时间 / 待上传数；「立即同步」；上次未完成的原因（不用「错误」「异常」措辞）；时效性说明脚注 |
| T3 | 设置 | 服务器、数据类型、首次同步范围、连接 AI Agent、数据共享同意、删除服务器数据、断开连接、隐私政策、关于 |

### 二级页面
| ID | 页面 | 内容 |
|---|---|---|
| S1 | 服务器配置 | 地址、Token（遮罩，可替换）、服务端版本、各类型样本数、「重新测试」 |
| S2 | 数据类型 | 同 O4 的 Toggle 列表；新增类型会再次请求 HealthKit 授权 |
| S3 | 连接 AI Agent | MCP 地址（Worker 地址 + `/mcp`，可复制）；Segmented：Claude Code / Codex / Claude Desktop / 通用 JSON，各给配置片段（ShareLink / 复制）；MCP Token 按服务器存入独立 Keychain 条目，验证后可复制 |
| S4 | 数据共享同意 | 同意时间、同意内容原文；「撤回同意」（confirmationDialog）→ 进入暂停状态 |
| S5 | 删除服务器数据 | 显示将删除的条数 → 二次确认（destructive） |
| S6 | 断开连接 | 说明会停止上传、清除本机保存的地址与 Token、服务器数据不会删除 → 可选「同时删除服务器数据」 |
| S7 | 概览详情 | 每种类型一个页面，Swift Charts + 数据来源 |

## 3. 状态清单（原型需可切换）
| 状态 | 出现位置 | 表现 |
|---|---|---|
| 连接成功 | O2 / S1 | 绿色对勾行：服务端版本、样本数 |
| Token 错误（401） | O2 / S1 / T2 | 红色行 + 「重新输入 Token」 |
| 地址无法访问 | O2 / S1 / T2 | 检查地址格式、网络、Worker 是否部署 |
| 服务端版本过旧 | O2 / S1 / T2 | 显示当前 / 需要的版本 + 「如何更新」 |
| 无健康数据 | T1 / O6 | ContentUnavailableView：引导去「设置 › 健康 › 数据访问与设备 › HealthBridge」自查（不说「你拒绝了权限」） |
| 锁屏等待 | T2 | 「iPhone 锁定时无法读取健康数据，解锁后会继续同步」（中性灰，非错误） |
| 超过 24 小时未同步 | T1 状态条 / T2 | 黄色提示：可能原因（App 被上划关闭、后台刷新关闭、网络）+「立即同步」 |
| 同步已暂停 | T1 / T2 | 本机模式 / 已撤回同意两种文案；按钮「连接服务器」/「重新同意」 |

## 4. 待确认的关键产品假设

|---|---|---|---|
| A1 | 引导顺序 | 按方案：先连接（O2）再同意（O3） | 连接测试只调 `/v1/ping`，不发送健康数据，不违反 5.1.2(i)；不同意时丢弃刚填的地址和 Token |
| A2 | 本机模式入口 | 介绍页「仅在本机查看」、O2「暂不连接」、O3「不同意」三处 | 方案文档没有本机模式，本条为新增 |

## 6. 做原型时新增、需要确认的细节
- 「锁屏等待」在 App 内实际看不到（打开 App 时 iPhone 已解锁，会立即开始补齐），所以原型把它画成「正在补齐锁定期间的数据」。因此 A15 的「解锁后计算」不会出现，改为显示「正在读取」。
- 删除服务器数据后，仍保持连接、继续上传之后产生的新数据。
- 扩大首次同步范围会补传更早的数据；缩小范围不删除服务器上已有的数据。
- 「Token 无效」和「无法连接」时，删除服务器数据的按钮不可用。

## 7. Token 初始化与快捷复制（2026-11-03 用户确认）

- O2 新增“生成新 Token”，使用系统安全随机数生成两枚 256 位 Token，草稿独立保存在 Keychain，不改动当前连接。
- 用户分别复制到 Cloudflare 两个 Secrets 并部署后，使用草稿测试连接。可同时导入已有 MCP Token，也可稍后在 S3 导入。
- S3 验证只读 Token 后保存，支持复制地址、只读 Token 和 Codex / Claude Code / 通用 JSON 配置。预览隐藏 Token，复制凭据时设置 2 分钟剪贴板有效期。
- 未实现 Cloudflare 管理登录或服务器自动初始化；客户端生成不等于服务器已经配置。

## 8. 首次安装快速连接（2026-11-03 用户修正）

- README 提供官方 Deploy to Cloudflare 按钮。部署端生成长期上传和只读凭据，用户只设置一个首次连接口令。
- 部署完成后打开连接页，输入口令，获得 5 分钟一次性链接/二维码；App 首屏以“开始连接”为主入口，扫码或粘贴后只确认服务器。
- 凭据保存后仍必须经过独立共享同意和系统健康读取授权。连接本身不上传数据。
- 手动填写 Token、生成草稿及凭据管理保留在高级入口。Agent 页默认只显示客户端选择和复制配置，预览与凭据细节折叠。
- 本页旧 O2 和第 7 节的客户端生成流程现为兼容路径，不是首次安装的默认开通流程。
