# HealthBridge 隐私说明

HealthBridge 仅从 Apple HealthKit 读取你选择的数据类型，不向 HealthKit 写入或修改样本。
概览在本机计算，写入 Token、按服务器保存的 MCP 只读 Token 和未使用的生成草稿分别使用设备钥匙串保存。你主动复制时，Token 或含只读 Token 的客户端配置会进入支持通用剪贴板的系统剪贴板，并设置 2 分钟有效期；粘贴到其他应用的副本由该应用管理。应用不包含广告、分析或第三方追踪 SDK。

只有你在独立的共享说明页面明确同意后，所选健康数据才通过 HTTPS 传往你配置的服务器。心率和步数在 iPhone 上汇总为小时统计后上传；其他所选类型以样本形式上传，包含时间、时区、数据来源和设备类型。服务器在你自己的 Cloudflare 账号中运行，开发者不运营收集这些数据的中心服务。

持有 MCP Token 的客户端和你连接的 AI 服务可以读取已上传数据；这些服务如何处理数据取决于其隐私政策，请只连接可信赖的服务。

撤回同意停止后续上传并取消在途任务，但无法撤回已被服务器接收的请求。已上传数据仍保留，直到你主动删除。断开连接仅清除本机连接配置，不自动删除远端数据。你可以选择先删除再断开。

删除服务器数据为逻辑删除；Cloudflare 的备份与历史恢复保留遵循其服务政策。若需完全撤销服务，请在自己的 Cloudflare 账号中管理 Worker、D1 和 Token。更换 MCP Token 可以阻止旧客户端继续访问。

系统健康读取权限由你在 iPhone 设置中管理。HealthBridge 不知道某项读取是否被拒绝，空数据不构成授权状态判断。

此文为当前自部署 MVP 的数据处理说明，不代表 App Store 隐私标签、公开服务合规或上架审核已完成。

首次快速连接使用部署所有者设置的连接口令及短时票据。二维码不包含长期 Token；配对验证成功后，App 通过 HTTPS 获取并保存凭据，仍需另行明确同意才上传健康数据。服务器仅保存票据与设备领取标识的摘要；为限制口令猜测，短时记录散列后的来源标识和请求次数。配对状态不随健康数据删除而清空。
